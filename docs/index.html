DeepSeek Query Console

Talks directly to your own self-hosted llama.cpp server on vast.ai — nothing is sent anywhere else.

This model is uncensored (refusal behavior deliberately removed) and, once PUBLIC_EXPOSE=true, is reachable by anyone who has the API key — vast.ai has no IP allowlisting. Treat the key like a password; destroy the instance (./destroy.sh or the Destroy workflow) when you're done testing.

Saved only in this browser's local storage — never sent anywhere but the host above.

Trouble connecting?
  • Self-signed certificate warning: open https://HOST:PORT/v1/models directly in a new tab first and click through the warning ("Proceed anyway" / "Visit site") — the browser remembers that exception, then this page's requests will go through.
  • Using the SSH tunnel instead of a public endpoint? set Host to localhost, Port to 8000, Scheme to http, and make sure the ssh_tunnel_command from your deploy is still running in a terminal.
  • 401 Unauthorized: the API key doesn't match what the instance was deployed with.
  • Nothing responds at all: the instance may still be downloading the model / building llama.cpp on first boot — this can take 10-30 minutes.
